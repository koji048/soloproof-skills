# Post Templates — Market Validation Test

โครงสร้างเดียวกันทุกโพสต์ (เพื่อให้เทียบผลแฟร์):
**HOOK (ปัญหา/ความเชื่อผิด) → DEMO (ผลลัพธ์จริง โชว์ให้เห็น) → PAYOFF (ได้อะไร ประหยัดเท่าไหร่) → CTA (ลิงก์ waitlist เดียวกัน)**

กติกา: โชว์ของจริงเสมอ (screenshot / คลิปหน้าจอ / ตัวเลข) ห้ามเล่าทฤษฎีลอยๆ

---

## โพสต์ทดสอบ #1 — หัวข้อ: Claude สำหรับคนทำงานออฟฟิศ

**HOOK:** คนส่วนใหญ่ใช้ AI แค่ "ถาม-ตอบ" แล้วบอกว่ามันไม่เวิร์ค... ทั้งที่ปัญหาไม่ใช่ AI แต่คือวิธีใช้

**DEMO:** ผมโยนไฟล์รายงานประชุม 2 ชั่วโมงให้ Claude — ได้กลับมาเป็น (1) สรุปประเด็นตัดสินใจ (2) action items แยกตามเจ้าของงานพร้อม deadline (3) ร่างอีเมล follow-up ถึงทีม ทั้งหมดใน 3 นาที [แนบ screenshot ก่อน-หลัง]

**PAYOFF:** งานที่เคยใช้เวลาทั้งบ่าย เหลือไม่ถึงกาแฟหนึ่งแก้ว และนี่คือ workflow ที่ผมใช้จริงในงานทุกสัปดาห์ ไม่ใช่ demo สวยๆ

**CTA:** ผมกำลังทำคอร์สสอน workflow แบบนี้ทั้งระบบ สำหรับคนทำงานที่ไม่ต้องเขียนโค้ด — สนใจลงชื่อรอก่อนได้ที่ [ลิงก์] (ฟรี ไม่ผูกมัด)

---

## โพสต์ทดสอบ #2 — หัวข้อ: สร้างระบบ content ด้วย Claude Skills/Agents

**HOOK:** ผมทำ content คนเดียว แต่มี "ทีม" 12 คนทำงานให้ทุกวัน — ทีมนั้นคือ AI agents ที่ผมสร้างเอง

**DEMO:** จากคลิปดิบ 1 คลิปที่ถ่ายด้วยมือถือ ระบบจัดไฟล์ → ถอดเสียงไทย → ตัดซับ → ออกเป็น Reel พร้อมโพสต์ โดยผมพิมพ์สั่งประโยคเดียว [แนบคลิปหน้าจอระบบทำงาน]

**PAYOFF:** เวลาผลิตต่อชิ้นลดลงจากหลายชั่วโมงเหลือหลักนาที และระบบนี้ทำซ้ำได้ทุกวันโดยคุณภาพไม่ตก

**CTA:** กำลังทำคอร์สสอนสร้างระบบแบบนี้ตั้งแต่ศูนย์ — เรียนจบได้ Skills ติดมือไปใช้เลย ไม่ใช่แค่ดูวิดีโอ ลงชื่อรอที่ [ลิงก์]

## โพสต์ทดสอบ #3 — หัวข้อ: Claude Code สำหรับคนไม่ใช่ developer

**HOOK:** ผมไม่ได้เป็น programmer สายตรง แต่ผมสร้างเครื่องมือใช้เองในงานได้แล้วหลายตัว — จุดเปลี่ยนคือ Claude Code

**DEMO:** ตัวอย่างจริง: dashboard วิเคราะห์ข้อมูลที่ผมสั่งเป็นภาษาไทยธรรมดา ไม่ได้เขียนโค้ดเอง [แนบ screenshot ผลงาน + คำสั่งที่ใช้]

**PAYOFF:** เส้นแบ่งระหว่าง "คนใช้โปรแกรม" กับ "คนสร้างโปรแกรม" บางลงมาก — คุณไม่ต้องเรียนเขียนโค้ด 2 ปี แค่ต้องรู้วิธีสั่งงานให้เป็น

**CTA:** กำลังทำคอร์ส Claude Code ฉบับคนไม่ใช่ dev ภาษาไทย — ลงชื่อรอรุ่นแรกที่ [ลิงก์]
