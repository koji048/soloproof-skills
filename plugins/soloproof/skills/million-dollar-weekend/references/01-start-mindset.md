# 01 — Start: Freedom Number, Ask Muscle, และการปลดล็อกคนที่ไม่กล้าเริ่ม

ใช้ไฟล์นี้เมื่อผู้ใช้ติดที่ "ใจ" ไม่ใช่ที่ "วิธี" — สังเกตจากการที่เขาถามคำถามเชิงวิธีการเยอะมากแต่ไม่เคยลงมือสักอย่าง นั่นคือความกลัวที่ปลอมตัวมาเป็นความรอบคอบ

## ความกลัว 2 ชั้นที่ต้องแยกให้ออก

หนังสือระบุว่ามีแค่สองอย่างที่ฆ่าธุรกิจก่อนเกิด และวิธีแก้คนละแบบ:

1. **กลัวเริ่ม** — แก้ด้วยการย่อขั้นแรกให้เล็กจนปฏิเสธไม่ลง (ดู NOW not How ด้านล่าง)
2. **กลัวถาม/กลัวโดนปฏิเสธ** — แก้ด้วยการฝึกโดนปฏิเสธในที่ที่ไม่มีอะไรเสีย (Coffee Challenge)

วินิจฉัยด้วยคำถาม: *"ถ้าผมบอกว่าไอเดียนี้เวิร์กแน่ ๆ 100% คุณจะทักคนแรกเลยไหม"*
- ตอบว่าจะทัก → กลัวเริ่ม (กลัวเสียเวลาเปล่า)
- ตอบว่ายังไม่กล้าอยู่ดี → กลัวถาม (กลัวสายตาคนอื่น) ← อันนี้แก้ยากกว่าและต้องแก้ก่อน

## Freedom Number

**คืออะไร:** รายได้ต่อเดือนที่ทำให้ชีวิตแบบที่อยากได้เป็นไปได้ ไม่ใช่ตัวเลขในฝัน

**ทำไมสำคัญ:** เป้า "รวย" ไม่มีวันจบ ทำให้ท้อและเลื่อนออกไปเรื่อย ๆ ส่วนเป้า "45,000 บาท/เดือน" แปลงเป็นการกระทำวันนี้ได้ทันที

**วิธีทำกับผู้ใช้ (อย่าให้เขาตอบลอย ๆ):**

1. ให้ลิสต์ค่าใช้จ่ายจริงต่อเดือน: ที่พัก อาหาร เดินทาง ผ่อน ประกัน ครอบครัว บันเทิง
2. บวก buffer 20%
3. ได้ตัวเลข F = Freedom Number
4. **แปลงเป็นหน่วยขาย** — นี่คือขั้นที่ทำให้มันมีพลัง:

```
F = 45,000 บาท/เดือน
ถ้าขายคอร์สราคา 1,500 → 30 คน/เดือน → 1 คน/วัน
ถ้าขายคอนซัลต์ 5,000  → 9 ดีล/เดือน  → 2 ดีล/สัปดาห์
ถ้าขาย membership 390 → 116 คน (ต่อเนื่อง)
```

5. ถามปิดท้าย: **"1 คนต่อวัน ฟังดูเป็นไปไม่ได้ไหม"** — เกือบทุกคนจะตอบว่าเป็นไปได้ นั่นคือช่วงเวลาที่เขาเปลี่ยนจาก "ฝัน" เป็น "งาน"

**เป้ารองที่ทรงพลังกว่า:** Kagan ย้ำว่าเป้าจริง ๆ ของสัปดาห์แรกคือ **บาทแรก** ไม่ใช่ Freedom Number เพราะระยะห่างจาก 0 → 1 บาท ยากกว่า 1 → 100,000 บาทมาก มันคือการพิสูจน์ว่าคุณเป็นคนที่ทำให้เงินเกิดขึ้นได้

## NOW, Not How

**หลักการ:** ลงมือก่อน หาวิธีระหว่างทาง เพราะคำถาม "ทำยังไง" ไม่มีวันหมด และแต่ละคำถามคือใบอนุญาตให้เลื่อนออกไปอีกวัน

**วิธีใช้ในบทสนทนา:** เมื่อผู้ใช้ถาม "แล้วต้องทำ X ยังไง" ให้ตอบให้สั้นที่สุดที่ยังใช้งานได้ แล้วต่อด้วยการกระทำที่มีเดดไลน์ทันที

> ผู้ใช้: "แล้วต้องจดบริษัทก่อนไหม ต้องเสียภาษียังไง"
> ตอบ: "ยังไม่ต้อง — รับโอนเข้าบัญชีส่วนตัวได้ ถ้ารายได้เกิน 1.8 ล้าน/ปีค่อยคุยเรื่อง VAT ตอนนั้นเป็นปัญหาที่ดีมาก ตอนนี้กลับมาที่ Dream Ten: คนที่ 1 คือใคร"

**การกระทำที่เล็กจนปฏิเสธไม่ลง:** ถ้าผู้ใช้ยังไม่ขยับ ให้ย่อขั้นลงเรื่อย ๆ จนเขาทำได้ในนาทีนี้ — ไม่ใช่ "ทัก 10 คน" แต่เป็น "เปิด LINE แล้วบอกผมมา 3 ชื่อที่อยู่บนสุดของแชท"

## Ask Muscle — "No ASK, No Get"

คนส่วนใหญ่ไม่ได้ถาม พวกเขา *ใบ้*, *หวัง*, *เกริ่น* แล้วน้อยใจเมื่อไม่ได้ การถามตรง ๆ เป็นทักษะที่ฝึกได้เหมือนกล้ามเนื้อ และมันฝ่อถ้าไม่ใช้

**หลักคิดที่เปลี่ยนเกม:** *Selling is helping.* ถ้าคุณเชื่อจริงว่าสิ่งที่คุณทำช่วยชีวิตเขาได้ การไม่บอกเขาคือการเห็นแก่ตัว ความอึดอัดที่คุณรู้สึกคือคุณกำลังปกป้องอีโก้ตัวเอง ไม่ใช่ปกป้องเขา

### Coffee Challenge

ครั้งต่อไปที่ซื้อกาแฟ ให้ขอส่วนลด 10% — ไม่มีเหตุผลประกอบ แค่ขอ

จุดประสงค์ไม่ใช่ส่วนลด แต่คือการได้ประสบการณ์ตรงว่า **โดนปฏิเสธแล้วไม่มีอะไรเกิดขึ้น** โลกไม่แตก ไม่มีใครจำ

เวอร์ชันไทยที่ใช้ได้จริง (เลือกให้เข้ากับบุคลิกผู้ใช้):
- ขอลดราคาที่ตลาดนัด/ร้านขายของ
- ขออัปเกรดห้องตอนเช็คอินโรงแรม
- ขอเพิ่มไข่ดาว/ขอน้ำเปล่าฟรีที่ร้านข้าว
- ขอ discount code ตอนแชทกับ CS ของแบรนด์ออนไลน์
- ทักคนที่ห่างหายไปนานเพื่อขอคำแนะนำ

ให้ผู้ใช้ทำ **ก่อน** เข้า Dream Ten ถ้าเขาบอกว่า "ไม่กล้าทักเพื่อน" — เพราะการฝืนทักทั้งที่ยังกลัวจะทำให้ข้อความออกมาขอโทษขอโพย และการขายจะพัง ซึ่งจะยิ่งยืนยันความกลัวเดิม

### Rejection Goals

พลิกตัวชี้วัด: แทนที่จะตั้งเป้า "ปิดได้ 3 ดีล" (ควบคุมไม่ได้ ทำให้ท้อ) ให้ตั้งเป้า **"โดนปฏิเสธ 10 ครั้งสัปดาห์นี้"** (ควบคุมได้ 100% และทำให้การโดนปฏิเสธกลายเป็นความคืบหน้า)

ผลข้างเคียงที่ตั้งใจ: พอต้องล่าคำว่า "ไม่" ผู้ใช้จะทักคนเยอะขึ้นมาก และจะได้ "ใช่" มาโดยบังเอิญ

## เมื่อโดนปฏิเสธ — สคริปต์ 4 คำถาม

นี่คือเครื่องมือที่มีค่าที่สุดในหนังสือ เพราะมันเปลี่ยน "ไม่" ให้เป็นข้อมูล เครือข่าย และบางทีเป็นยอดขาย ใช้ทุกครั้งที่ผู้ใช้รายงานว่าโดนปฏิเสธ:

1. **"ทำไมถึงไม่สนใจครับ"** → ได้เหตุผลจริง (มักไม่ใช่ราคา)
2. **"พอจะนึกถึงใครที่น่าจะชอบสิ่งนี้ได้บ้างไหม"** → ได้ lead ใหม่ฟรี คนที่ปฏิเสธมักอยากช่วยชดเชย
3. **"ถ้าเป็นแบบไหนถึงจะน่าสนใจสำหรับคุณ"** → ได้ทิศทางปรับข้อเสนอจากปากลูกค้า
4. **"แล้วแบบนั้นคุณจะจ่ายเท่าไหร่"** → ได้ราคาที่ตลาดยอมรับจริง

เพิ่มเติมสำคัญ: **แยก "ไม่" ออกจาก "ยังไม่ใช่ตอนนี้"** ส่วนใหญ่เป็นอย่างหลัง ให้ผู้ใช้ตั้งเตือนตามต่อ และรู้ไว้ว่า yes ส่วนมากมาที่ครั้งที่ 2–3 การตามต่อไม่ใช่การรบกวน มันคือส่วนหนึ่งของงาน

## Experiment Mindset

ทุกอย่างคือการทดลอง ไม่ใช่การสอบ เป้าคือ **จำนวนการทดลอง** ไม่ใช่อัตราชนะ

ตั้งเป้าเป็นสิ่งที่ควบคุมได้เสมอ:

| แบบที่ทำให้ท้อ | แบบที่ทำให้เดินต่อ |
|---|---|
| ได้ลูกค้า 3 คน | ทัก 10 คน |
| คลิปนี้ต้องปัง | ลง 100 คลิป |
| ต้องเจอไอเดียที่ใช่ | ทดสอบ 5 ไอเดียในเดือนนี้ |

และอย่าให้ผู้ใช้นิยามคุณค่าตัวเองจากผลลัพธ์ — Kagan เตือนว่าการวัดตัวเองจากความสำเร็จเทียบคนอื่นจะกัดกินแรงจูงใจเสมอ เพราะมีคนเก่งกว่ารวยกว่าอยู่ตลอด ให้วัดจากสิ่งที่ทำในแต่ละวันแทน

## Checklist ปิด Mode D

ก่อนปล่อยผู้ใช้ไป ต้องมีครบ:

- [ ] Freedom Number แปลงเป็นจำนวนชิ้น/เดือนแล้ว
- [ ] ทำ Coffee Challenge (หรือนัดว่าจะทำเมื่อไหร่แน่นอน)
- [ ] มี rejection goal เป็นตัวเลขของสัปดาห์นี้
- [ ] มีการกระทำ 1 อย่างที่จะทำ **ภายในวันนี้** พร้อมเวลาที่ระบุชัด
