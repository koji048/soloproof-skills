# กลไก hook แยกตามแพลตฟอร์ม

ไฟล์อ้างอิงที่ไม่ค่อยเปลี่ยน — ว่าด้วยฟิสิกส์ของแต่ละฟีด ซึ่งเปลี่ยนช้ากว่าเทรนด์รายตัวมาก
ใช้อ่านระหว่างที่ agent รีเสิร์ชกำลังรัน ใช้เป็น fallback เวลา WebSearch ได้ข้อมูลบาง
และใช้เช็กสติเวลา agent รายงานอะไรที่ขัดกับพฤติกรรมจริงของแพลตฟอร์ม

เหตุผลที่ hook ต่างกันตามแพลตฟอร์มไม่ใช่เรื่องสไตล์ แต่เพราะทั้งสามฟีดวางคนดูไว้ใน
สถานการณ์ทางกายภาพคนละแบบตอนวินาทีที่ศูนย์

---

## TikTok

**สถานการณ์วินาทีที่ 0:** เต็มจอ เสียงเปิด นิ้วโป้งคนดูวางอยู่บนจอพร้อมปัดทิ้งแล้ว ไม่มีอะไรอื่นให้เห็น
retention ใน 3 วินาทีแรกคือ input การจัดอันดับที่แรงที่สุดตัวเดียว และการดูซ้ำมีน้ำหนักสูง

**แปลว่า:** hook คือสิ่งที่ **พูด** ไม่ใช่สิ่งที่เขียน มันต้องแลนดิ้งก่อนที่แคปชั่นจะถูกอ่านทัน
การค่อย ๆ ปูตายเรียบ เฟรมแรกควรมีการเคลื่อนไหวหรือผลลัพธ์อยู่แล้ว

pattern ที่ได้ผล:

- **ผลลัพธ์ก่อน** — เปิดด้วยของที่เสร็จแล้ว แล้วค่อยเล่าย้อนกลับ ซื้อความสนใจด้วยหลักฐาน
  แทนที่จะด้วยคำสัญญา
- **ขัดความเชื่อ** — "หยุดทำ X" / "X ที่ทุกคนสอนคือผิด" ได้ผลเพราะความไม่เห็นด้วยไปกดรีเฟล็กซ์
  การปัดทิ้ง ใช้ได้ต่อเมื่อเนื้อหาเถียงเรื่องนั้นจริง ๆ
- **นับ** — "3 อย่างที่..." เป็นการบอกความยาวที่คนดูคาดหวังไว้ ซึ่งดัน completion ขึ้น
- **ค้างไว้ (open loop)** — ตั้งคำถามที่คลิปไปเฉลยตอนจบ ดันการดูซ้ำ แต่เผาความเชื่อใจถ้าเฉลยกลวง
- **POV / สถานการณ์** — โยนคนดูเข้าไปในฉากที่เขาจำได้ แข็งกับคอนเทนต์สาย relatable และเล่าเรื่อง
  อ่อนกับคอนเทนต์สอน

keyword บน TikTok อยู่ใน **คำพูดและตัวหนังสือบนจอ** ไม่ใช่แค่แฮชแท็ก — TikTok index ทรานสคริปต์
keyword ที่ไม่เคยถูกพูดออกมาดัง ๆ คือเสียของไปครึ่งหนึ่ง

## Facebook

**สถานการณ์วินาทีที่ 0:** คลิปอาจ autoplay แบบไม่มีเสียงอยู่ในฟีดที่แน่นไปหมด และบรรทัดแรกของ
แคปชั่นอยู่เหนือคลิป คนดูมักอายุมากกว่า เลื่อนช้ากว่า และมีแนวโน้มอ่านก่อนดู
คอมเมนต์กับแชร์มีน้ำหนักสูงต่อการกระจาย

**แปลว่า:** hook มักคือ **บรรทัดแรกของแคปชั่น** ไม่ใช่ตัวคลิป บรรทัดนั้นถูกตัดที่ประมาณ
1-2 บรรทัดก่อนคำว่า "ดูเพิ่มเติม" การตัดสินใจกดขยายจึงเกิดตรงนั้น

pattern ที่ได้ผล:

- **เล่าเรื่องจริง** — บรรทัดแรกที่มีรายละเอียดเฉพาะเจาะจง Facebook ให้รางวัลกับ dwell time
  และรูปแบบเล่าเรื่องรั้งมันได้ดีที่สุด
- **คำถามที่คนอยากตอบ** — คำถามที่คนอยากพิมพ์ตอบในคอมเมนต์ คอมเมนต์ดัน reach ที่นี่
  มากกว่าแพลตฟอร์มอื่น
- **ประโยชน์ชัดเจน** — ตรง ๆ ไม่ต้องเก๋ คนดู Facebook ตอบสนองแย่กว่ากับการเปิดแบบคลุมเครือ
  ที่ได้ผลบน TikTok
- **เตือน / ระวัง** — อัตราแชร์สูง เพราะการแชร์คำเตือนคือการกระทำทางสังคม ต้องมีข้อควรระวังนั้น
  อยู่ในเนื้อหาจริง

เพราะเสียงมักปิด hook ที่ต้องอาศัยการได้ยินต้องเบิร์นประโยคเดียวกันเป็นตัวหนังสือลงในเฟรมด้วย

## Instagram (Reels)

**สถานการณ์วินาทีที่ 0:** เต็มจอเหมือน TikTok แต่การกระจายส่วนใหญ่มาจากการส่งให้เพื่อนและการเซฟ
มากกว่า watch time ล้วน ๆ ความสวยและอัตลักษณ์ทางภาพมีน้ำหนักมากกว่า และตัวหนังสือบนจอมักแข่งกับ
ประโยคที่พูด

**แปลว่า:** hook มักคือ **ตัวหนังสือบนเฟรมแรก** และเนื้อหาต้องมีเหตุผลให้คน **ส่งต่อหรือเซฟ**
ไม่ใช่แค่ดูจบ

pattern ที่ได้ผล:

- **บันทึกไว้ใช้ (save-bait เวอร์ชันซื่อสัตย์)** — ลิสต์หรือของอ้างอิงที่คนดูอยากเก็บไว้ใช้ทีหลัง
  ใช้ได้ต่อเมื่อเนื้อหาเป็นของอ้างอิงจริง
- **ก่อน/หลัง** — ความต่างทางภาพในเฟรมแรก แข็งมากบน IG เพราะแพลตฟอร์มนำด้วยภาพ
- **แท็กเพื่อน** — คอนเทนต์ที่ระบุประเภทคนที่คนจำได้ การส่งต่อเป็นสัญญาณจัดอันดับที่หนักกว่าที่อื่น
- **เบื้องหลัง / process** — คนดู IG ตามคนมากกว่าตามหัวข้อ คอนเทนต์กระบวนการสร้างการฟอลโลว์
  มากกว่าสร้างยอดวิว

แฮชแท็กบน IG อ่อนลงมากในฐานะกลไกค้นพบ แต่ยังทำหน้าที่ติดป้ายหัวข้ออยู่ ให้มอง keyword ของ IG
เป็นส่วนผสมของตัวหนังสือบนจอ ถ้อยคำในแคปชั่น และชุดแฮชแท็กเล็ก ๆ — ไม่ใช่การถม 30 แท็กแบบสมัยก่อน

## ความพังที่เจอบ่อยข้ามแพลตฟอร์ม

- **hook เดียว ก๊อป 3 ที่** ถ้าประโยคเดียวกันถูกวางลงทั้งสามแพลตฟอร์ม แปลว่าไม่ได้ใช้ผลรีเสิร์ช
  สถานการณ์ที่วินาทีศูนย์ต่างกัน ประโยคเปิดจึงต้องต่างกัน
- **เขียนตาม keyword** การเขียน hook ให้เข้ากับคำที่มาแรงแทนที่จะเข้ากับเนื้อหา ทำให้เกิดคำสัญญา
  ที่คลิปทำไม่ได้ watch time ร่วง แล้วอัลกอริทึมก็อ่านมันถูกต้องว่าเป็นคลิปไม่ดี
- **ยัดแฮชแท็ก** ทั้งสามแพลตฟอร์มย้ายไปใช้การจำแนกจากตัวเนื้อหาแล้ว ชุดแท็กเล็กแต่ตรง
  ชนะชุดใหญ่ในทุกแพลตฟอร์มตอนนี้
- **hook ที่เป็นแค่ชื่อเรื่อง** "วันนี้จะมาสอนเรื่อง..." คือการประกาศ ไม่ใช่ hook
  มันขอความอดทนที่ฟีดไม่ให้
