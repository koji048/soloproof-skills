# แหล่งตัวเลข: อะไรดึงได้ อะไรดึงไม่ได้

ไฟล์นี้มีไว้กันไม่ให้สกิลนี้แต่งตัวเลข ปัญหาคือรายงานรีเสิร์ชโซเชียลที่ดูน่าเชื่อที่สุด
มักเป็นรายงานที่ยอดวิวถูกกุขึ้นมา เพราะตัวเลขทำให้ข้อความดูหนักแน่นโดยไม่มีใครไปตรวจ
กติกาในไฟล์นี้จึงไม่ใช่เรื่องความละเอียด แต่เป็นเรื่องว่าผู้ใช้จะเอาผลลัพธ์ไปตัดสินใจได้จริงไหม

---

## สถานะจริงของแต่ละแหล่ง (ตรวจแล้ว ก.ค. 2569)

| แหล่ง | ดึงอัตโนมัติได้ไหม | ให้อะไร |
|---|---|---|
| Google Trends RSS (`trends.google.com/trending/rss?geo=TH`) | ✅ ได้ | เทรนด์การค้นหารายวันของไทย + `approx_traffic` เป็นตัวเลขจริง |
| Google Trends เปรียบเทียบคำ (interest over time) | ❌ ถูกบล็อก | ต้องให้ผู้ใช้เปิด trends.google.com เอง |
| TikTok Creative Center (หน้าเว็บ) | ❌ เป็น JavaScript ล้วน WebFetch ได้แต่โครงเปล่า | ต้องให้ผู้ใช้เปิดเอง |
| TikTok `creative_radar_api` | ❌ ตอบ `40101 no permission` และการดึงอัตโนมัติผิด ToS | — |
| TikTok Research API | ❌ เฉพาะสถาบันวิชาการใน US/EEA/UK/สวิส/บราซิล ครีเอเตอร์ไม่มีสิทธิ์ | — |
| Meta Content Library | ❌ เฉพาะ non-profit ต้องผ่าน IRB | — |
| ยอดแฮชแท็ก IG / FB สาธารณะ | ❌ ปิดไปแล้ว | — |
| Analytics ของช่องผู้ใช้เอง | ผู้ใช้เปิดให้ดูได้ | แม่นที่สุด — บอกได้ว่าคำไหนทำให้คนเจอเขาจริง |

**สรุปที่ต้องยอมรับ:** ไม่มีทางดึงยอดวิว/ยอดโพสต์ของแฮชแท็กไทยแบบอัตโนมัติได้เลยตอนนี้
สกิลนี้จึงไม่รับปากเรื่องนั้น และต้องไม่ทำเป็นว่าทำได้

---

## Google Trends RSS — ใช้ยังไงให้ตรงกับความจริง

ดึงได้ด้วย WebFetch ตรง ๆ ไม่ต้อง auth:

```
https://trends.google.com/trending/rss?geo=TH
```

แต่ละ `<item>` มี `<title>` (คำที่คนค้น) และ `<ht:approx_traffic>` (เช่น `2000+`, `5000+`)

**ข้อจำกัดที่ต้องเข้าใจก่อนใช้:** นี่คือเทรนด์ข่าวรวมทั้งประเทศ ไม่ใช่ keyword ของ niche
ตัวอย่างผลจริงวันหนึ่ง: ทองคำ, แมนยู, รัฐสภา, กรมอุตุนิยมวิทยา, ราคาน้ำมัน

แปลว่า **โดยปกติมันจะไม่เกี่ยวกับคอนเทนต์ของผู้ใช้เลย และนั่นคือผลลัพธ์ที่ถูกต้อง**
ประโยชน์จริงของมันมีอย่างเดียวคือเช็กว่ามีกระแสที่คอนเทนต์นี้เกาะได้พอดีไหม
ถ้าไม่มี ให้เขียนบรรทัดเดียวว่าเช็กแล้วไม่มีกระแสที่เกี่ยว แล้วเดินต่อ

ห้ามลากเทรนด์ข่าวเข้ามาในตารางเพียงเพราะมันมีตัวเลขสวย ถ้าคอนเทนต์ไม่ได้พูดถึงเรื่องนั้น
มันคือ "ไม่เกี่ยว" ตามกติกาใน Step 2 เหมือน keyword อื่นทุกตัว

## กติกาติดป้ายตัวเลข

ทุกตัวเลขที่ปรากฏในผลลัพธ์ต้องมีป้ายกำกับชั้นความน่าเชื่อถือ ผู้ใช้จะได้รู้ว่าอันไหนเอาไปอ้างต่อได้

- **[ยืนยันแล้ว]** — ดึงมาสด ๆ จากแหล่งที่เข้าถึงได้ในรอบนี้ ระบุแหล่งและวันที่
- **[อ้างจากแหล่ง]** — มีคนรายงานไว้ในบทความ ระบุ URL และวันที่ ผู้ใช้ตัดสินความน่าเชื่อเอง
  ระวังตัวเลขประเภท "hook แบบนี้เพิ่ม reach 4 เท่า" ที่มักมาจากบล็อกขายเครื่องมือและไม่มีวิธีวัดกำกับ
  ถ้าตามรอยไม่เจอวิธีวัด ให้ตัดตัวเลขทิ้งแล้วเก็บแต่ข้อสังเกตเชิงคุณภาพ
- **[ยังไม่ยืนยัน]** — pattern ที่สมเหตุสมผลแต่ไม่มีตัวเลขรองรับ ใส่ได้ แต่ต้องไม่มีตัวเลขปลอมแปะ

ถ้าไม่มีตัวเลขให้เลย ให้เขียนคำอธิบายเชิงคุณภาพแทน เช่น "แท็กนี้มีคนไทยในสายนี้ใช้จริง"
ดีกว่าตัวเลขที่กุขึ้นมาเสมอ เพราะผู้ใช้เอาไปเช็กต่อได้ว่าจริงไหม

## Checklist 5 นาทีให้ผู้ใช้เช็กเอง

แนบท้ายผลลัพธ์เมื่อมีแถวที่ติดป้าย [ยังไม่ยืนยัน] อยู่ นี่คือของที่ผู้ใช้ทำเองได้เร็วกว่า
และแม่นกว่าที่สกิลนี้จะหาได้

1. **ช่อง search ในแอป** — พิมพ์ keyword ในแอปแล้วดู autocomplete นั่นคือคำที่คนพิมพ์จริง
   ไม่ใช่คำที่เราเดา ทำได้ทั้ง 3 แพลตฟอร์ม เร็วสุดและตรงที่สุด
2. **TikTok Creative Center** → `ads.tiktok.com/business/creativecenter` เลือก region ไทย
   ดูยอดโพสต์แฮชแท็กย้อนหลัง 7/30/120 วัน (ต้องล็อกอิน)
3. **แตะแฮชแท็กในแอป** — หน้าแฮชแท็กบอกยอดโพสต์รวม เทียบกันเองได้
4. **Analytics ช่องตัวเอง** — ดูว่าคลิปเก่ามีคนมาจาก search ด้วยคำไหน อันนี้มีค่ากว่าเทรนด์ตลาด
   เพราะมันคือคำที่พาคนมาหา*คุณ*ได้จริง
5. **Google Trends เปรียบเทียบคำ** — trends.google.com ใส่ 2-5 คำ เลือกประเทศไทย
   ดูว่าคำไหนขึ้นคำไหนลง ทำเองในเบราว์เซอร์ได้ (สกิลดึงให้ไม่ได้)

ถ้าผู้ใช้อยากให้ช่วยอ่านหน้าจอตอนเขาเปิด Creative Center ไว้แล้ว ใช้ Chrome tools อ่านได้
— นั่นคือการอ่านสิ่งที่เขาเปิดดูอยู่ ต่างจากการดึงข้อมูลอัตโนมัติเป็นชุด
