# Launch 7 Days — เจ็ดวันแรกหลังโพสต์ขาย

โพสต์ที่ขึ้นแล้วคือจุดเริ่ม ไม่ใช่เส้นชัย เจ็ดวันแรกตัดสินว่าโพสต์นั้นกลายเป็นธุรกิจ
หรือกลายเป็นโพสต์ที่ค่อย ๆ เงียบไป

## ขั้นตอน

1. **ถามให้ได้ 3 อย่างก่อนวางแผน:** โพสต์ขึ้นวันไหน (วันที่จริง) / ขายอะไร ราคาเท่าไหร่ /
   ช่องทางที่คนจะทักคืออะไร (LINE OA? DM?) — ขาดข้อไหนถามข้อนั้น ห้ามเดา
2. **สร้างแผน 7 วัน หนึ่งวันหนึ่งงาน** ลงไฟล์ `แผน-7-วัน.md` โดยใช้**วันที่จริงบนปฏิทิน**:
   - วัน 1-2: ตามคนที่กดสนใจแต่ยังไม่ทัก (คนกดไลก์/เม้นคือรายชื่อลูกค้า ไม่ใช่กำลังใจ)
   - วัน 3: โพสต์ตามผล — เล่าสิ่งที่เกิดขึ้นจริงพร้อม**ตัวเลข** (กี่คนเห็น กี่คนทัก) ไม่ใช่โพสต์ขายซ้ำเฉย ๆ
   - วัน 4-5: ทักตรงหาคนที่เคยบ่นปัญหานี้ (รายชื่อจากการ์ด 3 คนของเวิร์กชอป ถ้ามี)
   - วัน 6: ปรับหนึ่งอย่างจากข้อมูลจริง (ราคา/ถ้อยคำ/รูป — อย่างเดียว ห้ามรื้อหมด)
   - วัน 7: สรุปตัวเลข — เห็นกี่คน ทักกี่คน จ่ายกี่บาท แล้วตัดสินใจ: ไปต่อ / ปรับ / เปลี่ยนไอเดีย
     (ศูนย์บาทไม่ใช่ความล้มเหลว มันคือข้อมูล — แนะนำให้รัน skill `aar` ถอดบทเรียนตรงนี้)
3. **เตรียมชุดข้อความตอบแชท 3 สถานการณ์** ปรับจากข้อเสนอจริงของผู้ใช้ ลงไฟล์ `ตอบแชท.md`:
   - คนถาม "ขายอะไร/ยังไง" → ตอบสั้น + ลิงก์หน้าขาย + คำถามกลับหนึ่งข้อ (เพื่อรู้ปัญหาเขา)
   - คนสนใจแต่ลังเล → ยกการันตีขึ้นพูด + ถามว่าติดตรงไหน — **ห้ามลดราคาใน 7 วันแรก**
   - คนโอนแล้ว → ขอบคุณ + บอกชัดว่าจะได้อะไร เมื่อไหร่ ช่องทางไหน + ขอ 1 อย่าง: บอกต่อหรือรีวิว
4. ถ้าผู้ใช้ใช้ LINE OA: แนะนำตั้ง auto-reply กับ keyword ตามที่ทำในเวิร์กชอป
   แต่**ถ้าตั้งไม่ทันหรือระบบไม่ให้ ให้ตอบมือไปก่อน 7 วันแรก** — ความเร็วตอบสำคัญกว่าระบบสวย

## กติกา

- ทุกงานต้องเล็กพอทำเสร็จใน 30 นาที/วัน — ผู้ใช้ส่วนใหญ่มีงานประจำ
- ห้ามให้ผู้ใช้ "รอดูก่อน" เกิน 1 วัน — การรอคือ loop เดิมที่พาเขามาเรียน
- ตัวเลขทุกตัวในแผนต้องนับได้จริง ไม่ใช้คำว่า "เยอะขึ้น" "ดีขึ้น"
