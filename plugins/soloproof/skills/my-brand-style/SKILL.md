# My Brand Style — สไตล์ภาพประจำแบรนด์ของคุณ

ภาพที่ดูเป็นแบรนด์เดียวกันทุกใบ สร้างความจำได้มากกว่าภาพสวยแบบคนละทิศ
skill นี้คือ "กติกาภาพ" ของคุณ — ฉากเปลี่ยนได้ทุกภาพ แต่สไตล์ห้ามเปลี่ยน

## แบรนด์ของฉัน (กรอกครั้งเดียว — Claude: ถ้าส่วนนี้ยังเป็น [.....] ให้สัมภาษณ์ผู้ใช้ก่อนแล้วเขียนเติม)

- **สไตล์ภาพ:** [เช่น flat illustration / ภาพถ่ายโทนอบอุ่น / minimal line art / 3D soft]
- **สีพื้นหลัง:** [โค้ดสีหรือคำอธิบาย เช่น ครีมอุ่น #F5F1E8]
- **สีหลัก (เส้น/ตัววัตถุ):** [เช่น เทาเข้ม #222]
- **สี accent — ใช้กับของสำคัญชิ้นเดียวต่อภาพ:** [เช่น ส้มอิฐ #B9541F]
- **อารมณ์ภาพ:** [เช่น สงบ จริงใจ ไม่โอ้อวด / สดใส เป็นกันเอง / พรีเมียม นิ่ง]
- **ตัวละครในภาพ (ถ้ามีคน):** [เช่น คนเอเชียวัยทำงาน แต่งตัวธรรมดา ท่าทางสงบ]
- **สิ่งต้องห้ามของแบรนด์:** [เช่น ห้าม gradient ห้าม 3D เงาแวว ห้ามจรวด/หลอดไฟ/ถ้วยรางวัล]

## กติกาที่ใช้กับทุกแบรนด์ (ไม่ต้องกรอก)

1. **accent สีเดียว ชิ้นเดียวต่อภาพ** — สี accent ชี้ "จุดความหมาย" ของภาพ
   ถ้าอยากทาสองชิ้น แปลว่าคอนเซปต์ภาพยังไม่คมพอ กลับไปคิดฉากใหม่
2. **ห้ามมีตัวหนังสือในภาพ** — ข้อความไปใส่ทีหลังตอนจัดเลย์เอาต์เสมอ
3. **ฉากเป็นเรื่องของแต่ละภาพ** — อย่าลอกฉากจากภาพก่อนหน้า ให้คิดฉากใหม่ที่ตรงข้อความของภาพนั้น
   ใช้ของธรรมดาในชีวิตจริง เลี่ยงอุปมาดราม่า (หน้าผา พายุ ยอดเขา)
4. **ภาพปกที่จะมีพาดหัวทับ:** วางวัตถุไว้หนึ่งในสามของเฟรม เว้นอีกครึ่งเป็นพื้นว่างสีพื้นหลังไว้ให้ตัวหนังสือ

## วิธีเขียน prompt

เขียน prompt เป็น**ภาษาอังกฤษ**เสมอ (โมเดลภาพตามภาษาอังกฤษแม่นกว่า) โครง 5 ส่วน:

```
[1 Style] <สไตล์ + สีจากหัวข้อ "แบรนด์ของฉัน" แปลงเป็นอังกฤษ>
[2 Scene] <ฉากรูปธรรมหนึ่งย่อหน้า + ระบุว่าชิ้นไหนเป็นสี accent เพราะอะไร>
[3 Composition] <ใส่เฉพาะเมื่อเป็นปกที่ต้องเว้นที่พาดหัว>
[4 Hard constraints] <สิ่งต้องห้ามของแบรนด์ + no text or lettering anywhere>
[5 Aspect ratio] <ตามงาน เช่น 1:1 สำหรับปกสินค้า, 9:16 สำหรับ story>
```

### ตัวอย่าง (แบรนด์สมมติ: flat illustration ครีม/เทา/ส้มอิฐ)

โจทย์: "ทำปกสินค้าคอร์สเรื่อง 'เริ่มก่อนพร้อม'"

```
Flat editorial illustration. Warm cream background (#F5F1E8). Limited palette:
dark grey (#222222) linework, ONE burnt-orange accent (#B9541F), warm neutral
greys. Calm, honest, understated — not motivational, not glossy.

Scene: A person seen from behind, standing at an open door with soft light
beyond it. The door is the single burnt-orange element — it is the decision
to start. Everything else stays cream and grey.

Composition: subject in the right third; left half completely empty cream,
reserved for headline text.

Hard constraints: no gradients, no 3D render, no drop shadows, no trophies or
lightbulbs. No text or lettering anywhere in the image.

Aspect ratio 1:1.
```
