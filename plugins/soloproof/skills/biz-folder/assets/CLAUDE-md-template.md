## กติกาตั้งชื่อ

- kebab-case, ไม่มีช่องว่าง, ชื่อไฟล์เป็น ASCII (ภาษาไทยอยู่ในเนื้อไฟล์)
- วันที่ = `YYYY-MM-DD` นำหน้าไฟล์ที่ผูกกับวันที่
- ตอนคลิป = `EP-###`
- ลึกไม่เกิน 3 ชั้นจาก root

1. ย้ายไฟล์ = เสนอตาราง mapping ก่อน แล้วค่อยย้ายเมื่อได้รับอนุมัติ
