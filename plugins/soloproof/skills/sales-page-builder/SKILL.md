# Sales Page Builder — หน้าขายหนึ่งหน้า จบจากใบข้อเสนอ

หน้าขายที่ดีของคนตัวคนเดียวคือ "แผงลอยหน้าปากซอย ไม่ใช่ห้าง" —
คนเปิดจากมือถือ เลื่อนครั้งเดียวรู้เรื่อง กดทักได้ทันที

## ต้องมีก่อนเริ่ม

ไฟล์ข้อเสนอของผู้ใช้ (มักชื่อ `offer.md`) ที่มีอย่างน้อย: ช่วยใคร / ให้ได้อะไร /
ราคา / การันตี ถ้ายังไม่มี ให้หยุดแล้วบอกผู้ใช้ไปทำข้อเสนอก่อน (skill offer-design)
**ห้ามแต่งข้อเสนอแทนผู้ใช้เด็ดขาด** — หน้าขายเอาของจริงจากไฟล์มาจัดเรียงเท่านั้น

## โครงหน้า — 6 ก้อน เรียงตามนี้เสมอ

1. **พาดหัว** = ประโยคคุณค่าจากไฟล์ offer ("ผมช่วย [ใคร] ให้ได้ [อะไร]") — ห้ามคิดใหม่
2. **ปัญหา 2-3 บรรทัด** ในภาษาที่ลูกค้าใช้เอง (ถ้าผู้ใช้มีคำพูดจริงจากการสัมภาษณ์ ใช้คำนั้น)
3. **ของที่ได้** — bullet สั้น ของจริงที่ส่งมอบ ไม่ใช่คำสวย
4. **ราคา + การันตี** — ตัวเลขชัด อยู่ในกรอบเดียวกัน
5. **วิธีซื้อ/ทัก** — ปุ่มเดียว ลิงก์ LINE OA หรือช่องทางเดียวที่ผู้ใช้มีจริง
6. **ผู้ขายคือใคร** — 2 บรรทัด + จุดที่เชื่อถือได้จริง (ไม่มีก็ข้าม อย่าแต่ง)

## กติกาการทำไฟล์

- HTML ไฟล์เดียว ไม่มี dependency ภายนอก ฟอนต์ระบบ ขนาดตัวอักษรอ่านง่ายบนมือถือ (อย่างน้อย 16px)
- สีจากแบรนด์ผู้ใช้ (ถ้ามี skill my-brand-style ให้ใช้สีจากนั้น) — ปุ่มหลักสีเดียว จุดเดียว
- ห้ามใส่ตัวนับถอยหลังปลอม รีวิวปลอม ตัวเลขปลอม — ความน่าเชื่อถือของคนตัวเล็กมีค่ากว่า conversion หลอก ๆ
- จบงานทุกครั้งด้วย: (ก) ไฟล์ HTML ส่งให้ผู้ใช้ (ข) บอกทางขึ้นเว็บที่ง่ายที่สุด 1 ทาง
  (เช่น Netlify Drop ลากไฟล์วาง) (ค) เตือนให้เปิดจากมือถือจริงก่อนแชร์

## เกณฑ์เสร็จ

ผู้ใช้เปิดลิงก์/ไฟล์จากมือถือแล้วตอบได้ใน 10 วินาทีว่า: ขายอะไร ราคาเท่าไหร่ ทักที่ไหน — ครบสามข้อคือเสร็จ
